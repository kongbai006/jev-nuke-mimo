# Jev 聊天助手 · Nuke 版

适配 **Nuke** 微信模块的 JS ESM 脚本。对方私聊发消息后，本地立刻判断意图 / 危险等级 / 情绪；可选接入**任意 OpenAI 兼容大模型**（小米 MiMo、DeepSeek、通义、智谱、OpenAI 等）给出建议和 3 条候选回复，候选自动复制到剪贴板，**手动粘贴发送，绝不自动发消息**。

> 同系列：
> - WA (WAuxiliary) 版：`kongbai006/jev-wa-mimo`
> - WeKit 版：`kongbai006/jev-wekit-mimo`
> - QStory 版：`kongbai006/jev-qstory-mimo`

## 安装

在 Nuke 的「脚本」页面导入 `main.js`（同目录下的 `manifest.json` 和 `config.schema.json` 会随包一起带上）。启用后，在聊天框输入 `/jev` 打开配置。

## 配置

脚本设置页（齿轮图标）里填：API 地址、密钥、模型、关系描述、上下文轮数。默认接入小米 MiMo，可改成任意 OpenAI 兼容端点。

> 注意：部分 Nuke 版本在调用大模型时会让微信原生页面崩溃，所以「接入大模型决策」默认关闭，需要手动打开。

## 行为说明

- 只分析单人私聊，群聊忽略；
- 情绪分 开心 / 难过 / 生气，无匹配显示「平静」；
- 候选回复**不会自动发**，自动复制到系统剪贴板，微信输入框长按粘贴后挑一条发；
- 判断结果仅供娱乐参考。
